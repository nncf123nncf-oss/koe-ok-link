# お客さまの声の掲載OKリンク

100日100プロダクトチャレンジ Day094（2026-11-09）

もらった感想を、載せてよいか相手に確かめるWebページです。

- もらった感想を貼り付けると、1文ずつに区切って並べます
- 「載せていいか聞くリンク」を相手に送ると、相手は文ごとに「載せてOK」か「載せないで」を選び、名前の出し方（呼び名のまま／イニシャル／名前を出さない）と載せてよい場所を選んで、返事のリンクを送り返せます
- 返事のリンクを開くと、「載せてOK」の文だけで1080×1080のカード画像を作って保存できます。誰に・いつ・どこまでOKをもらったかは、この端末の「声の控え」に残せます
- 相手は登録なしでリンクを開けます。文は書き換えられません（選べるのは載せる・載せないだけ）

感想を広告や販売ページに載せるときの表示の決まり（効果の言い方など）は、消費者庁の案内などで確認してください。このページは、載せてよいかの判断をするものではありません。

## 使い方

`index.html` をブラウザで開きます。「見本を入れる（講座の感想）」で架空の例を入れられます。

## 扱うデータ

- 入力した内容を当サイトのサーバーに保存する仕組みはありません。声の控えは、この端末のブラウザ（localStorage）に残ります
- リンクには、感想の内容がURLの `#` 以降に入ります。リンクを受け取った人は、その内容を見られます
- リンク・メールアドレス・電話番号らしい文字は入れられないようにしています（すべての言い方は防げません）
- リンクの画面は、リンクに入っている内容を表示するだけで、当サイトは内容や、返事が本人から届いたものかを確かめていません
- アクセス解析（Cloudflare Web Analytics）でページの閲覧状況を計測しています
